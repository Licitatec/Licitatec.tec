LICITATEC — código-fonte do website

Ficheiros incluídos:
- index.html: página inicial
- contato.html: formulário e contactos
- style.css: estilos responsivos
- script.js: animações e comportamento do formulário
- favicon.svg: ícone do site
- manus-routes.json: declaração das rotas do website

Para testar localmente, abra index.html num navegador ou execute um servidor estático na pasta. O site carrega Bootstrap e Bootstrap Icons a partir de CDNs.

O formulário não usa um backend: após validação, abre o programa de e-mail do visitante com os campos preenchidos para licitatec1000@gmail.com. O website não envia nem armazena os dados automaticamente.
